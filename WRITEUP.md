What went wrong, and how I fixed it. My first version compared whole documents and gave a marketing job a 0.31 match against a data analyst resume, so one number wasn’t trustworthy. I switched to comparing individual requirement lines against resume lines. Then I found that the model scored “LLMs” against “large language models” at only 0.14, so I added a hand-written alias list that expands abbreviations before matching. After that, both scored 1.00. Later, a test I wrote showed that empty or fully filtered job text crashed the app, so I added a check and 10 automated tests.

What I learned. I learned how embeddings and chunking work, how to build and deploy a Streamlit app, how to package it with Docker, and how to use Git and the terminal day to day. Most of all, I learned to break a big project into small daily tasks, which is how I finished it.
